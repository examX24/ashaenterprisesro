================================================================================
📌 2. COMPONENT-BY-COMPONENT DETAIL
================================================================================

1️⃣ RFID RC522 (Card Reader):
   - SDA  -----> ESP32 D5
   - SCK  -----> ESP32 D18
   - MOSI -----> ESP32 D23
   - MISO -----> ESP32 D19
   - IRQ  -----> (Khaali)
   - GND  -----> ESP32 GND
   - RST  -----> ESP32 D22
   - 3.3V -----> ESP32 3V3

2️⃣ OLED DISPLAY (0.96 inch Screen):
   - GND  -----> ESP32 GND
   - VDD  -----> ESP32 3V3 (Dhyan rahe 3.3V pe hi lagana hai)
   - SCK  -----> ESP32 D15
   - SDA  -----> ESP32 D21

3️⃣ BUZZER (Beep Speaker):
   - (+) Lamba taar -----> ESP32 D13
   - (-) Chhota taar ----> ESP32 GND

4️⃣ FLOW SENSOR (ZJ-S201 / YF-S201):
   - Lal taar   -----> ESP32 VIN (Yahi 5V deta hai)
   - Kala taar  -----> ESP32 GND
   - Peela taar -----> ESP32 D34

5️⃣ RELAY MODULE (12V) & MOTOR (230V):
   Relay Low Voltage Control:
   - IN  -----> ESP32 D26
   - VCC -----> 12V Adapter ka Plus (+)
   - GND -----> 12V Adapter ka Minus (-) AUR ESP32 GND (Dono ek sath)

   Relay AC Motor Switch (230V Mains - Dhyan se):
   - 230V Live supply wire Relay ke "COM" par lagao.
   - Motor ka pehla wire Relay ke "NO" par lagao.
   - 230V Neutral wire seedha motor ke doosre wire se jod do.

================================================================================
📌 3. SABHI GND KA COMMON CONNECTION RULE
================================================================================
ESP32 ka GND pin main zero-volt line hai.
Yeh sabhi ek sath judte hain:
- RFID GND
- OLED GND
- Buzzer (-)
- Flow Sensor Kala taar
- Relay GND aur 12V Adapter Minus (-)

Yeh sab aapas mein judkar ESP32 ke GND se contact mein rahenge.

================================================================================
📌 4. POWER SUPPLY
================================================================================
1. 5V Mobile Charger / USB Cable -> ESP32 ke USB Port mein.
2. 12V DC Adapter -> Relay ke VCC aur GND par.
3. 230V Bijli Plug -> Motor aur Relay COM/NO par.
